# AC Services Dubai — Professional HVAC Service Website

Production-ready, responsive website and instant WhatsApp booking dispatch system for **AC Services Dubai**, providing 24/7 air conditioning repair, maintenance, cleaning, and emergency cooling services across Dubai, UAE.

## Features

- **Responsive Design**: Fluid mobile-first experience tested across 360px to 1920px viewports.
- **Instant WhatsApp Booking Dispatch**: Client-side validation and URL-encoded WhatsApp booking message generator.
- **Click-to-Call CTAs**: Direct emergency dispatch hotline (`055-5269352` / `+971 55 526 9352`).
- **Sticky Mobile Conversion Bar**: Fixed bottom bar on mobile viewports with quick WhatsApp and Call buttons.
- **Service & Pricing Catalog**: Transparent pricing starting from AED 99 (Cleaning), AED 149 (Repair), and AED 199 (Maintenance).
- **FAQ Accordion**: Semantic, accessible FAQ accordion covering cost, response time, warranties, and areas.
- **SEO & Schema**: Full Open Graph, Twitter cards, meta descriptions, LocalBusiness JSON-LD schema, robots.txt, and sitemap.xml.

## Technology Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide Icons
- **Fonts**: Outfit (Headings) & Inter (Body)

## Project Setup

### Install Dependencies
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

### Run Tests & Verification
```bash
node test-site.mjs
```
